# A policy digest is SHA-256 over the bytes a policy's author signed, so it is
# not sha256sum of policy.json, and since ticket 19 it is the digest of the
# policy and not of the reference value set beside it. Each number below was
# printed by emit-refvals when it wrote the document, checked against
# 'emit-refvals -digest-of' on the document as delivered, and checked again
# against the line the guest holding that document printed at start.
