================================================================================
3. replay-ccel.py
================================================================================
Not replayable on a workstation, and not a ticket 21 regression.  The script
reads the live ACPI table at /sys/firmware/acpi/tables/data/CCEL
(replay-ccel.py:38, CCEL_DATA) and takes no path for it; its only argument is an
optional quote file.  Run here it prints

  CCEL data table unreadable: [Errno 2] No such file or directory:
    '/sys/firmware/acpi/tables/data/CCEL'
  NO EVENT LOG: an RTMR from this platform is 48 opaque bytes.

which is the guest-side tool refusing off a guest.  probe-tdx-eventlog.sh scp's
it onto the VM for exactly that reason (probe-tdx-eventlog.sh:67).  Its recorded
output is docs/snp/evidence/tdx/eventlog/replay.txt, and the recorded ccel.bin
beside it is what predict-rtmr2.py reads above.
