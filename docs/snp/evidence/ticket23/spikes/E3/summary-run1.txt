RFC 8446, published by the IETF in August 2018, defines version 1.3 of the Transport Layer Security (TLS) protocol, which provides authentication, confidentiality, and integrity for communications over an insecure network. It obsoletes TLS 1.2 (RFC 5246) and earlier ticket/OCSP mechanisms (RFCs 5077 and 6961), while updating RFCs 5705 and 6066. TLS 1.3 introduces major improvements over TLS 1.2, including removal of legacy and non-forward-secret algorithms (static RSA/DH), a streamlined handshake with encrypted messages after the ServerHello, a redesigned HKDF-based key schedule, and support for 0-RTT data at the cost of certain replay-related security guarantees. The protocol consists of two main components: a handshake protocol that negotiates cryptographic parameters and keys, and a record protocol that protects application data using those keys. The document also specifies detailed cryptographic computations, state machines, compliance requirements, and security considerations, including extensive analysis of properties like forward secrecy, replay attacks, and traffic analysis.
