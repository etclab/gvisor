## update-grub cannot move grub.cfg's bytes
There is no userspace in this image that could run it: grub loads the initrd and the initrd
is the guest, so Ubuntu's /sbin/init never executes. The immutable flag on the inode is the
second line of defence, not the first. The configuration itself reads grubenv nowhere --
no load_env, no save_env, no recordfail, no initrdfail -- so RTMR2 does not depend on how
any previous boot ended, which is the one way docs/tdx-rtmr2-prediction.md found for a
pristine image's RTMR2 to move.
