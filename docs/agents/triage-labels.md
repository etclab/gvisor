# Triage labels

The five canonical triage roles, recorded as a `Status:` line near the top of each issue file
(this repo uses the local-markdown tracker; see `issue-tracker.md`).

| Role | Label string |
|---|---|
| Needs triage | `needs-triage` |
| Needs info | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

Defaults, unchanged. Issues produced by `/to-tickets` are already agent-ready and are not
triaged; triage is for issues that arrive raw.
