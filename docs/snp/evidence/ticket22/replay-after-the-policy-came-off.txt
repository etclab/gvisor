Why it is the check worth making
--------------------------------

Ticket 22 takes policy.json off the config device and narrows what the digest
in the binding names. None of that is supposed to reach a verdict already
recorded: `attest-tool verify` never opened a policy document — its only policy
input is `-policy-digest HEX`, and no recorded row passes a file — so the change
either leaves every verdict alone or it has touched something it had no business
touching. Three of the 64 rows are the regression test for the half ticket 22
promises to keep: `snp-t05-badhex` and `snp-t05-shortdigest` drive
attest.ParsePolicyDigest directly and must still print the same two refusals,
and `snp-t05-v2-zerodigest` must still reach the allow-list comparison and lose
there (exit 3).

Method
------

Both binaries built from source, the base one from the commit this work started
at, with the evidence, the lists and the authored sets all taken from this
checkout so that every path in every transcript is the same string:

    REPO=/home/pniroula/Projects/gvisor-t22
    H=$REPO/docs/snp/evidence/ticket21/harness

    git archive 32a18ba24 attest | tar -x -C $W/base
    (cd $W/base/attest && GOPROXY=off go build -o $W/attest-tool-base ./cmd/attest-tool)
    (cd $REPO/attest   && GOPROXY=off go build -o $W/attest-tool-head ./cmd/attest-tool)

    for side in base head; do
      REPLAY_REPO=$REPO \
      REPLAY_LIST=$H/verdict-invocations-v2.txt \
      REPLAY_AUTHORED=$H/authored \
        bash $H/replay-verdicts.sh $W/replay-$side $W/attest-tool-$side verify
    done

    for f in $W/replay-head/*.txt; do
      diff <(tail -n +2 "$W/replay-base/${f##*/}") <(tail -n +2 "$f") \
        || echo "DIFF ${f##*/}"
    done

32a18ba24 is "Record E1: a QUIC stream has no FD to hand over…", the tip this
ticket's three commits were written on. The 47 retired invocations
(verdict-invocations-retired.txt) were not replayed: they carry
-binding-version, which ticket 21 removed, and they exit 1 on the usage line
before any verdict on either side of this change.

The transcripts themselves are not kept, for the reason ticket 21 gave: they are
64 files this harness regenerates in a minute, and the diff is the evidence.
