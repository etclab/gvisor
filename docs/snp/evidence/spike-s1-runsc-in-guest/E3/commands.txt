--- 2. the harness ----------------------------------------------------------

Reused from E2, byte for byte, not copied into this directory:
  $EV/E2/guest-like-ns.sh      the guest-shaped mount namespace
  $EV/E2/init-mount-check.sh   the verbatim check from init.rootfs:31-44

New here:
  build-img.sh   assembles the read-only image, same as E2's plus two empty
                 directories (/roshared, /roroot) that exist only so that a
                 read-only path can be handed to --shared-root and --root
  case.sh        one candidate per invocation

$ export EV=<repo>/docs/snp/evidence/spike-s1-runsc-in-guest
$ export SCRATCH=<the scratch directory above>
$ bash $EV/E3/build-img.sh
$ cp $EV/E2/guest-like-ns.sh $SCRATCH/e3/guest-like-ns.sh

One `unshare` per case, deliberately: the null-netns pin is not transient, so
a single namespace could only ever fail once and then stay failed. Each case
therefore starts from a namespace in which the check passes, and every case's
output begins by showing that.

$ unshare -Urmnpf $SCRATCH/e3/guest-like-ns.sh $SCRATCH/e3/img \
      /busybox sh /case.sh <case>

with, inside the namespace,
  BASE  = --platform=systrap --network=none --ignore-cgroups --rootless
  STATE = /run/st-<case>     (on the rw,noexec tmpfs, as in E2)
  TMPDIR= /tmp               (rw,noexec)
  bundle= /bundle            (on the read-only image root, root.readonly true)
